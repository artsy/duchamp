# CLAUDE.md

Instructions for Claude Code sessions working in this repository.

## Git commit conventions

If the session's `userEmail` context is `mounir.dhahri@artsymail.com`, add this
trailer to every commit message:

```
Co-authored-by: MounirDhahri <soussouheros@gmail.com>
```

This is scoped to that specific account so other engineers' Claude Code
sessions in this repo aren't misattributed to Mounir. Don't add this trailer
for any other `userEmail`.
